💡 KEY FEATURES

1. SUMMARIZE GROUPS & DRAFT REPLIES
   "Summarize #tech-team from past 24h and help me reply"
   → Bot searches RAG → reads your preferences → generates summary

2. SCHEDULE REMINDERS
   "Remind me in 5 minutes to check GitHub"
   → Bot creates cron job → sends reminder

3. RECURRING POSTS
   "Post 'Good morning!' daily at 9am in #announcements"
   → Bot registers daily cron job → posts automatically

4. GITHUB INTEGRATION
   "Create GitHub issue about the bug we discussed"
   → Bot searches RAG for context → creates issue

5. NOTION INTEGRATION
   "Create Notion page summarizing this week"
   → Bot queries RAG → formats → creates page
